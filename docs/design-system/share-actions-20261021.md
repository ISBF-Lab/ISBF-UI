# 课程资源、资料库和简历分享操作区

用户于 2026-10-20 通过三个浏览器注释指定本次布局，并补充：标题左对齐，申请分享与三点菜单右对齐。用户同时授权完成后直接上线。本记录只登记这三个操作区及资料库功能对齐的范围，不扩大其他页面的视觉批准。

标题保留原有字体和颜色，在可用空间内单行显示，长标题省略。右侧始终按“申请分享 → 三点菜单”排列，不再依据宽度把全部按钮一起折叠。按钮沿用现有主题强调色、pill 和至少 44px 的可操作高度；菜单沿用既有文字居中、透明条目、语义边框和主题背景。间距继续使用现有 space token。

桌面三点区域使用 float-kit 的 hover 和 click 触发方式，保留原生关闭、焦点和键盘行为；手机保留 click 入口。课程资源的申请分享回调不变。简历申请分享仍指向 `/isbf/workbench/resume/shares/new`，我的投稿与有权限时的收集链接设置收进菜单。

资料库继续使用独立的分类、分组、Topic 字段和数据；复用课程资源的管理表单、学号关联、我的贡献、管理与审核授权、目录维护和确认后软删除流程。普通成员看到 WPS 收集入口。`isbf_library_collection_form_url` 独立于课程资源设置，本次默认地址与课程资源相同。目录删除的预览、两次或三次确认及过期保护保留，不在发布过程中执行任何业务删除。

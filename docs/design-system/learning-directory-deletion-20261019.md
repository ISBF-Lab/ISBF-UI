# 课程与上级分类删除

2026-10-19（Asia/Taipei）承接 `learning-contributions-20261018.md` 已确认的课程目录和管理弹窗。用户明确要求课程删除、上级分类删除及查找用户头像，并授权完成隔离测试后直接上线，无需再次交由用户复测。

来源为已发布主题基线 `634885407968f062361aaca0f431b0f9f0bfccfc`，本次实现见 PR #101 的 `isbf-learning-directory-deletion.gjs`、目录编辑器、资源页面及管理弹窗。后端配套为 ISBF-Learning PR #8。正式部署记录保存固定提交及字段校验值。

- 删除入口沿用现有编辑课程和编辑上级分类弹窗，复用 DButton、DModal inline、原弹窗表面、间距及响应式规则。
- 空目录两次确认；课程含资料、上级分类含课程时三次确认。任意一步“返回”、关闭或 Escape 均取消整个删除流程。
- 第三次课程提醒严格使用“删除课程会将此课程内所有资料一并删除 请确认”；分类提醒使用“删除分类会将此分类内所有课程及资料一并删除 请确认”。使用 `strong` 和既有语义颜色 `--danger`，不引入新颜色或全局变体。
- 用户匹配结果使用原生 `dAvatar` 的 small 头像、姓名和 @用户名，间距复用 `--isbf-v2-space-2`，选择行为及账号关联保持不变。
- 沿用 `manage_resources` 权限；确认期间内容变化时从第一次重新确认。删除成功后刷新课程和资料，“我的贡献”随原生软删除同步更新。

验收覆盖真实应用内的取消、两次/三次确认、连带删除、剩余分类选择、普通用户无入口以及头像与账号选择；同时运行原生 RSpec、QUnit 和变更文件 lint。上述用户授权限定本次区域及交互，不扩展其他页面的视觉规范。

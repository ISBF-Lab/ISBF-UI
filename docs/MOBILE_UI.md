# ISBF 移动端界面约定

## 已确认的产品决定

- 底部导航为「首页、通知、工作台」。工作台的设计和业务能力待单独提供，当前入口显示为不可用。
- 发布框保留 Discourse 必需的标题与分类字段，正文仍是视觉重点。
- 用户端页面使用同一套导航和信息流视觉；Discourse Admin 保持官方界面。
- 主题使用 ISBF 标识与真实 Discourse 数据，不复制 X 的商标、广告或专有功能。

## 参考录屏对应的交互

| 页面 | 参考交互 | ISBF 实现依据 |
| --- | --- | --- |
| 首页 | 单栏信息流、顶部筛选、浮动发布入口 | Discourse 话题列表与原生 Composer |
| 发布 | 全屏输入、取消与发布、附件工具栏 | Discourse 原生 Composer，保留标题和分类 |
| 帖子 | 返回栏、正文与媒体、互动操作、底部回复入口 | Discourse Topic、Post 与原生回复按钮 |
| 通知 | 底栏可进入通知列表 | Discourse 用户通知 |
| 工作台 | 底栏占位 | 业务定义和设计尚未提供 |

## 待验证

在团队开发站点的独立预览主题上检查 390px 与 430px、明暗模式、登录和未登录、首页到帖子、回复、发布、搜索、通知、分类、标签、个人资料及浏览器 Console。通过前不更新默认主题。

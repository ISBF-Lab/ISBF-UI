# ISBF 桌面端 UI 基准与设计系统

日期：2026-09-27。实施分支：`codex/desktop-ui-foundation`。当前主题源码基线为 V3 `96b36ba`；团队开发站点默认仍为 V2（主题 ID 2），V3 是独立预览（主题 ID 3）。本文的现状判断来自仓库代码与已有预览记录，尚未取得本轮同尺寸的站点截图，视觉差异须在预览中复核。

## 1. 对照基准

目标借鉴 X 的桌面信息流结构与信息层级，不复制品牌或商业模块。X 官方帮助页确认首页有并列时间线标签和左侧书签导航；ISBF 以 Discourse 的真实路由和数据实现对应的校园社区路径：[X 首页时间线](https://help.x.com/en/using-x/x-timeline)。参考界面的英文栏目名在 ISBF 简体中文界面中统一改为中文，不保留 X 的英文产品文案。

统一以 1440 × 900、100% 浏览器缩放、简体中文、相同真实话题样本记录三张截图：原生 Discourse、当前部署的 ISBF V2、当前 V3 预览。每张再记录登录和未登录、浅色和深色状态。保存截图时记录 Core 提交、主题提交、主题 ID、日期和浏览器。登录态截图避免暴露个人信息。

| 区域 | 原生 Discourse / 现有 V3 | ISBF 目标 | 差异与处理 |
| --- | --- | --- | --- |
| 页面骨架 | 原生是论坛导航与列表；V3 已有左导航、600px 信息流、右栏 | 受限宽度三栏，正文始终是视觉焦点 | 保留 V3 骨架，按 1024/1280/1440/1920px 复核列宽与空白 |
| 顶部 | V3 信息流有标题与双标签 | 标题、筛选和首条内容形成连续阅读路径 | 统一高度、边界、悬停和选中态；保持真实列表路由 |
| 话题 | V3 用 Discourse 原生移动话题项呈现单列卡片 | 头像、标题、摘要、分类/标签、统计形成清晰层级 | 用排版与间距 token 规范密度；不伪造点赞或转发动作 |
| 发布 | V3 左侧按钮和信息流输入入口均打开原生 Composer | 在首页易发现、操作反馈清楚 | 保留 `/new-topic` 与原生权限判定 |
| 右栏 | V3 有搜索及真实热门/精华/分类入口 | 辅助发现，不抢占信息流 | 统一圆角、边框与悬停；无真实数据的校园模块暂不展示 |
| 语言与数据 | `/hot` 曾标为“为你推荐” | 标签准确说明排序 | 简体中文显示“热门”；`/latest` 显示“最新” |
| 交互状态 | 局部颜色、尺寸和状态值散落在 SCSS | 悬停、选中、焦点、禁用状态一致 | 建立语义 token，并复核键盘操作和对比度 |

## 2. Design system V1

实现位置为 `common/common.scss` 的 `:root`。颜色引用 Discourse 调色板变量，让站点浅色与深色方案继续生效；蓝色操作色为 ISBF 自己的 `#1769aa`，白色按钮文字的静态对比度约 5.77:1。若站点更换调色板，仍需在真实页面复核弱化文字与边框。

| 类别 | Token / 规则 | 用途 |
| --- | --- | --- |
| 颜色 | `background`、`surface`、`text`、`muted`、`border`、`border-strong`、`hover`、`active-surface`、`accent`、`accent-contrast`、`focus-ring` | 背景、文本、分隔、状态与主操作；由 `--isbf-v2-*` 命名空间承载 |
| 字体 | Discourse 的 `--font-family`；13/15/16/18/20px；字重 600/750 | 元信息、摘要、正文/标题、导航、页面标题 |
| Border | 1px 分隔线；颜色由 `border` 与 `border-strong` 定义 | Feed 行、列边界、面板 |
| 圆角 | 8px、16px、999px | 小控件、面板、胶囊按钮 |
| 间距 | 4/8/12/16/20/24/32px | 4px 基础网格；行内和容器间距 |
| 容器 | 最大 1260px；左栏 260px；信息流 600px；右栏 340px；栏间距 24px | 1280px 起完整三栏；超宽屏不拉伸正文 |
| 断点 | ≤600px 单列；601–1023px 紧凑导航；1024–1279px 双栏；≥1280px 三栏 | 与现有 V3 断点一致；桌面先检 1024/1280/1440/1920px |
| 状态 | hover 用 `hover`；当前导航用 `active-surface` 加字重；当前标签用底部强调线；focus-visible 用 3px 焦点环；快速过渡 120ms | 状态不能只靠颜色，尊重减少动画偏好 |

排版和几何值是本轮设计决策，不声称为 X 的精确规格。后续页面应先复用这些 token，只有明确的组件尺寸才使用局部数值。

界面文案以 `locales/zh_CN.yml` 为中文交付基准：首页、探索、通知、书签、个人资料、发布、搜索、热门、最新、校园热议。参考 X 的时间线命名只借鉴入口位置；ISBF 的“热门”和“最新”分别指向 Discourse `/hot` 与 `/latest`，不暗示关注关系或个性化推荐。现有 `en.yml` 保留供用户主动选择英文界面时使用。

## 3. 页面顺序与第一页面

按「首页信息流 → 话题详情 → 分类与标签 → 搜索 → 通知与书签 → 个人资料 → Composer」逐页完成。每页先存现状与目标截图，列出差异，再修改主题并复测。Admin 保持 Discourse 官方界面。

本轮第一页面是首页 `/hot` 和 `/latest`：完成 token 基础、热门标签语义、左导航选中态以及信息流标题/摘要/元信息的统一排版。内容继续来自 Discourse Topic；标题、分类、标签、搜索、通知、用户、发布继续使用原生路由和权限。`/hot` 不被描述为个性化推荐。

验收时在主题 ID 3 的独立预览中检查 1024/1280/1440/1920px，以及 390/430px 回归；分别检查浅/深色、登录/未登录、键盘焦点、话题跳转、搜索、Composer、通知、分类与标签、浏览器 Console。记录实际截图和结果后，才考虑替换团队开发站点的默认主题。当前只有静态代码检查可以在本机完成，不能视作浏览器验收。

## 官方扩展点与边界

主题继续使用 `renderInOutlet("before-main-outlet", ...)`、`topic-list-item-mobile-layout` / `topic-list-item-class` Transformer 和 `serialize_topic_excerpts` Theme Modifier。没有修改 Discourse Core，也没有新增 Plugin。Core 升级时复核这些扩展点和话题列表 DOM。

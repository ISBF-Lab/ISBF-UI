# 个人资料摘要精简

## 确认的界面

- 手机、桌面统一为单列：热门回复、热门话题、最多回复至、被谁赞的最多、赞最多，移除热门链接区块。
- 每组默认显示前3条，超过3条提供“展开更多／收起”；各组独立，不超过3条时没有折叠按钮。沿用原生顺序。
- 保留原生“更多回复／更多话题”路由入口，仍按原始摘要达到6条的条件显示；展开按钮只展示本次已返回的摘要项，不增加请求。
- 进入其他用户或离开后重新进入摘要时收起；同一资料下各组互不影响。状态仅在组件内，不写浏览器存储。

## 原生接入

使用 `below-user-summary-stats` outlet 的 `model`、`user` 参数，复用原生 UserSummarySection、UserSummaryTopic、UserSummaryUser。保留话题渲染扩展点、用户卡片、真实头像和计数、空状态及原生权限，不增加接口或复制后端数据。

原生没有包住这些区块的 wrapper outlet，因此只有在主题摘要成功挂载后，才隐藏对应的三组旧容器。热门分类、徽章、资料页头、统计与其他资料路由不属于本次替换范围。移除热门链接仅改变界面，不删除数据。

外层 each 以用户ID作为 key，切换资料时重建五个折叠实例。覆盖原生摘要的50%列宽、95%列表宽度及用户条目固定高度，采用主题变量和自适应单列，保留底栏安全间距。

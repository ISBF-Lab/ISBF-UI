# ISBF Campus Feed

国金综合平台当前用户端主题。源码以服务器主题导出包为基线，复用 Discourse 原生话题、用户、通知和 Composer；不修改 Core。

## 本次功能

- 左侧导航新增“日历 / 工作台”，手机底栏增加日历并启用工作台入口。
- 日历提供月视图、每日列表、个人行程与社区活动筛选。个人行程依赖独立的 [ISBF-Calendar](https://github.com/ISBF-Lab/ISBF-Calendar) 插件；社区活动读取 Discourse Events 的活动话题。
- 工作台以组件网格展示规划中的校园服务，所有卡片均标记“即将开放”且不可点击。
- 普通动态仍使用正文优先的 Discourse Composer；“校园活动”分类的活动发布保留原生事件 Composer 的标题与活动字段。

## 部署顺序

先安装 `ISBF-Calendar` 插件并迁移数据库，再启用站点已有的 Discourse Events 插件、创建“校园活动”分类并设置其发布权限。随后导入此主题，并把分类 ID、分类路径写入 `calendar_category_id`、`calendar_category_path` 主题设置。功能部署前不要把带日历导航的主题单独设为默认主题。

主题的简体中文和英文文案随 Discourse 站点或用户语言切换。首页“最新”映射 `/latest`，“官方”映射现有官方分类；工作台不展示虚构数据。

## 关联账号的设备验证

已获批准关联的账号支持密码或邮箱验证码验证。展开“验证此设备”后，选择“邮箱验证码”，向目标账号邮箱发送六位验证码并输入，再点击“验证并切换”。验证码十分钟内有效，已有双重验证仍需完成。邮件能力未启用时保留密码方式。

验证表单复用 Core FormKit，发送按钮复用 DButton；权限、验证码发送与校验由 ISBF-Account-Switch 插件执行。管理员可以新建关联；已获批准关联的普通账号和版主也能打开“关联账号”，验证设备并双向切换，但不显示新建关联表单。没有已批准关联的非管理员隐藏入口，审批和关联管理仍限管理员。更新线上主题时只应用账号菜单组件、账号名称样式和相关翻译键的增量，保留当前主题的头像框、其他字段、设置及组件。

关联列表和当前账号的名称、用户名完整换行显示，切换按钮位于关联账号信息下方。双重验证字段通过 FormKit 的说明及无障碍关联提示取码来源：动态码来自目标账号已绑定的身份验证器，备用码来自目标账号此前在安全设置中保存的备用码；它们与邮箱验证码分别校验。

设备验证按“账号 + 设备”复用。在同一浏览器设备上，a 验证 b、b 验证 c 后，只要 a↔c 的关联也已获批准，a↔c 就可以直接双向切换，无须再次验证。新的浏览器设备、授权到期、退出或撤销设备授权后仍需重新验证；关联本身的审批和参与者权限继续由服务器校验。测试环境的虚拟身份验证器不属于主题或插件发布内容。

2026-10-10 首次合并版本在独立服务器测试容器通过 24 项账号菜单 QUnit 测试（93 个断言），后端通过 54 项 RSpec 测试。真实桌面、527 × 871 手机和启用双重验证的 375 × 667 手机页面通过 15 项浏览器检查，覆盖收信、错误重试、密码方式、普通账号切回、新设备验证码、管理权限限制和无关关联拦截。撤销关联后入口隐藏也有回归测试。

同日按账号复用的最终候选版本，在独立服务器测试容器通过全部 64 项后端 RSpec 测试和 25 项 QUnit 测试（98 个断言）。桌面及两种手机尺寸通过 17 项真实浏览器检查，覆盖完整名称、无障碍说明、邮件与身份验证器联合校验，以及三账号直接往返、同浏览器新标签页、新设备隔离和其他未验证账号拦截；整个三账号流程仅提交最初的两次验证请求。后端回归还覆盖审批、过期、撤销和目标账号状态。该候选版本仍须用户复测确认后正式部署。
